# B. Sakthivel — Personal Developer Portfolio

A production-ready personal developer portfolio engineered with a **"Young engineer building serious technology"** aesthetic inspired by Linear, Vercel, and Raycast.

## 🚀 Quick Start

### 1. Run Locally
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) or [http://localhost:5173](http://localhost:5173) in your browser.

### 2. Build for Production
```bash
npm run build
```
Generates optimized production bundle in `./dist`.

### 3. Preview Production Build
```bash
npm run preview
```

---

## 🛠 Project Structure & Configuration

- **`src/data/portfolio.ts`**: **Centralized configuration file.** Update your bio, skills, flagship project details, additional projects, internship experience, achievements, certifications, and social URLs here without touching UI components.
- **`src/components/`**: Modular React components for each section (Navbar, Hero, About, Skills, Projects, VoxShieldCaseStudyModal, Experience, Achievements, Certifications, Education, Contact, Footer, Toast).
- **`src/index.css`**: Design tokens, dark mode palette, CSS variables, and audio waveform keyframes.
- **`public/`**: Favicon (`favicon.svg`), `robots.txt`, and `sitemap.xml`.

---

## 🛡️ Zero-Fabrication & Evidence-Based Policy

All details conform to verified inputs. Unconfirmed URLs or future internship contributions are marked with clear placeholders:
- `[ADD_GITHUB_URL]`
- `[ADD_LINKEDIN_URL]`
- `[ADD_EMAIL]`
- `[ADD_RESUME_URL]`
- `[Add verified internship contribution here]`
